# pinwarden

Runtime security gateway for the Model Context Protocol (MCP): full-schema pinning,
poisoning/shadowing detection, argument-level policies and audit logging between MCP
clients and servers.

> **Status: pre-alpha (Phase 0 — foundations).** Nothing is usable yet. See
> [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
